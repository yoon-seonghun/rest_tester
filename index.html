사용법

1. 기본
· 방식(GET/POST 등)을 고르고 주소를 입력한 뒤 보내기를 누릅니다. (단축키 Ctrl+Enter)
· 결과 숫자가 200번대면 성공, 400번대는 요청 내용 문제, 500번대는 서버 쪽 오류입니다.

2. 데이터 보내기
· 등록/수정(POST, PUT)은 본문(Body) 탭에서 JSON을 고르고 내용을 입력합니다.

3. 저장과 재사용
· 저장을 누르면 왼쪽 목록에 남아 다음에 클릭 한 번으로 다시 불러옵니다. (Ctrl+S)
· 보낸 요청은 최근 기록에 자동으로 100개까지 남습니다.
· 저장 내용은 RestTester_data.json 파일에 보관됩니다. (위치는 아래 5번 참고)
· 내보내기/불러오기로 동료와 요청 목록을 주고받을 수 있습니다.

4. 변수
· 변수 관리에서 baseUrl 같은 값을 등록하고 {{baseUrl}}/api/... 처럼 씁니다.

5. 응답 보기
· 표 보기: JSON 응답을 엑셀처럼 표로 정리합니다. 제목을 누르면 정렬, 검색, 열 선택, CSV(엑셀) 저장이 됩니다.
· 1700000000000 같은 숫자 시간값은 날짜 변환으로 읽기 쉬운 날짜로 바뀝니다. (원래 값은 원문 탭에서 확인)
· 원문: 서버가 보낸 그대로의 내용입니다. 보낸 요청: 서버로 실제 전송된 요청 원문입니다.
· 원문·보낸 요청 위쪽 검색창에서 글자를 찾을 수 있습니다. (Enter 다음, Shift+Enter 이전, 결과 영역에서 Ctrl+F)
· ⛶ 크게 보기: 결과 영역을 화면 가득 띄웁니다. Esc 또는 바깥쪽 클릭으로 닫습니다.

6. 문제가 생기면
· curl 복사를 눌러 개발 담당자에게 붙여넣어 전달하면 같은 요청을 바로 재현할 수 있습니다.
· 브라우저 탭을 닫았으면 프로그램을 다시 실행하면 화면만 다시 열립니다. (중복 실행되지 않음)
· 종료는 상단 종료 버튼.
· Windows: 창 없이 화면 오른쪽 아래 알림 영역(트레이) 아이콘으로 실행 — 아이콘 클릭: 화면 열기, 오른쪽 클릭: 종료
· Mac / Linux: 터미널에서 실행했다면 Ctrl+C 로도 종료됩니다.
