REST API 테스트 도구 - Windows

1. RestTester.exe 를 더블클릭합니다. 브라우저에 화면이 열립니다. (검은 창은 뜨지 않습니다)
   처음 실행 시 "Windows의 PC 보호" 경고가 뜨면 [추가 정보] -> [실행]
2. 프로그램은 화면 오른쪽 아래 알림 영역(트레이)에 아이콘으로 실행됩니다.
   - 아이콘 클릭: 화면 다시 열기
   - 아이콘 오른쪽 클릭 -> 종료  (또는 화면 상단 [종료] 버튼)
   - 아이콘이 안 보이면 알림 영역의 ^ (숨겨진 아이콘) 안을 확인하세요.
3. 저장된 요청은 exe 옆 RestTester_data.json 에 보관됩니다.
   새 버전으로 바꿀 때는 프로그램을 종료한 뒤 exe만 덮어쓰면 됩니다.
4. RestTester_Genian_NAC.json : 화면의 [불러오기]로 Genian NAC 예제 요청을 넣을 수 있습니다.
